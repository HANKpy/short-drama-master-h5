# 🎬 短剧全链条大师 H5

一个**纯前端、零依赖、离线可用**的短剧创作工作台。把短剧生产的完整方法论（题材/风格/景别/机位/打光/卡点/音效/分镜公式/提示词模板）编码为内置规则引擎，只需**粘贴一段梗概、点一下生成**，就能从梗概一路走到可直接投喂 AI 视频模型的提示词。

> 无需后端、无需 API Key、无需联网。单个 HTML 文件双击即用。

---

## ✨ 核心能力

**一句话梗概 → 一键跑完全链条**

输入梗概点「一键生成」，自动完成 6 个阶段（带实时进度环、阶段状态、滚动日志）：

```
🔍 解析梗概 → 📺 分集规划 → 👥 角色设定 → 📜 剧本创作 → 🎞️ 分镜拆解 → ✨ 提示词生成
```

- **梗概智能解析**：自动识别主角姓名、时代背景、金手指、核心危机，并贯穿全链条
- **分集**：按四幕结构（开局/发展/转折/高潮）规划，每集含主冲突 + 爽点 + 集尾卡点
- **分镜**：按 7/8 镜公式 + 五阶段情绪曲线拆解，每镜自动配景别/机位/运镜/打光/音效/时长/转场
- **双模型提示词**：
  - **Seedance 中文三段式**：素材声明 + 全局一致性约束 + 带时间码/转场/BGM 的分镜序列
  - **MiniMax H3 英文六段式**：Style + Reference lock + 累计时间码 Shot list + 音频层 + Negative prompt

**4 个主页面**

| 页面 | 说明 |
|---|---|
| 🚀 创作 | 梗概输入 → 一键流水线 → 图形化成果 |
| 📁 项目 | 本地多项目管理（新建 / 打开 / 重命名 / 删除） |
| 📚 知识库 | 17 题材 / 20 风格 / 12 景别 / 14 机位 / 10 打光 / 5 卡点 / 8 类音效 + **6 语系方言库**，点卡片看详情 |
| ⚙️ 我的 | 数据备份（导出 JSON）与清空 |

**主角方言（对接 `dialect-master` 内核）**

创作页可选 6 个语系 + 三档浓度，主角的台词会自动过一层方言，其余角色保持普通话作对照：

| 语系 | 片区 | 注音 | 提示词指令 |
|---|---|---|---|
| 粤语 | 广州西关音 | 粤拼 Jyutping | 用粤语说道{…} |
| 川渝话 | 成都/重庆（西南官话） | 谐音汉字 | 用四川话说道{…} |
| 东北话 | 辽吉黑（北方官话） | 谐音汉字 | 用东北话说道{…} |
| 上海话 | 市区新派（吴语） | 吴语协会式 | 用上海话说道{…} |
| 闽南语 | 泉漳/台语 | 台罗 Tâi-lô | 用闽南语说道{…} |
| 客家话 | 四县腔 | 白话字 | 用客家话说道{…} |

| 浓度 | 方言占比 | 形态 | 字幕 |
|---|---|---|---|
| **L1 点缀** | ≤15% | 普通话骨架＋语气词 | 可不挂 |
| **L2 半方言** | 30%~60% | 关键句方言整句（默认档） | 整句挂正字字幕 |
| **L3 重方言** | ≥70% | 大段方言正字 | 全程正字字幕 |

每句方言台词在剧本页都带一张**方言契约卡**：方言正字 / 普通话释义 / 注音（供配音参考）/ 加味点（语气词·感叹词·可用俗语）/ 字幕方案。提示词里自动写成「用粤语说道{…}」（H3 为 `speaks in Cantonese`）。

> 内核红线已内置：不硬造读音（拿不准的走注音体系说明）、俗语**只给建议不塞进台词**（避免段子拼盘）、方言只作用于主角（避免「南北混杂假方言」）、字幕是后期烧录所以片内仍不生成文字。

**成果页 4 个子标签**

| 标签 | 内容 |
|---|---|
| 总览 | 统计卡（集数/镜头数/总时长/角色数）+ 情绪曲线 + 景别配比 + 五阶段结构 + 角色档案 |
| 📜 剧本 | 按集展示四场剧本，**画面描述与台词均可直接编辑**；开方言时每句附方言契约卡 |
| 🎞️ 分镜 | 按集查看的分镜时间轴，镜头条按时长配色，逐镜可编辑 |
| ✨ 提示词 | 双模型输出（Seedance 中文三段式 / MiniMax H3 英文六段式），语法高亮、逐集复制、全部导出 |

> 角色**不是**「反派/女主/配角」这种占位名——反派、女主、配角都会按姓氏库 + 男女名库生成真名；主角的性别与外观也由梗概自动推断（输入「女主…」会得到青年女性造型），全程贯穿分镜与提示词。

## 🚀 快速开始

### 方式一：直接用单文件版（最简单，推荐手机 / 快速体验）

先生成单文件版（CSS 和 JS 全部内联，**不需要服务器，不需要同目录的其他文件**）：

```bash
python3 build.py
```

产物在 `dist/short-drama-master-h5.html`，下载后用任意浏览器打开即可。

### 方式二：本地开发（多文件源码版）

仓库地址：<https://github.com/HANKpy/short-drama-master-h5>

```bash
git clone https://github.com/HANKpy/short-drama-master-h5.git
cd short-drama-master-h5

# 起一个静态服务器（直接双击 index.html 也可以）
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899
```

### 方式三：GitHub Pages（手机随时随地访问）

仓库 Settings → Pages → Source 选 `main` 分支根目录，保存后访问：

```
https://HANKpy.github.io/short-drama-master-h5/
```

### 同步代码到 GitHub

正常网络下直接 `git push`：

```bash
git add -A && git commit -m "..." && git push
```

如果你的网络（代理）会掐断 git 的大 POST，报 `RPC failed; curl 52 Empty reply from server`，
改用脚本走 API 上传（PAT 只放环境变量，不要写进任何文件）：

```bash
GH_TOKEN=你的PAT ./sync_github.sh
```

## 💾 数据存储

所有项目数据存在浏览器 `localStorage`（key: `sdm_projects_v2`，当前项目 id 用 `sdm_current_v1`），**不上传任何服务器**。

- 换设备 / 换浏览器数据不会自动同步 → 请在「我的」页用**备份**导出 JSON，在另一台设备用**导入**恢复
- 清除浏览器数据会丢失项目 → 重要项目请先备份

## 🔧 二次开发指南

### 想改知识库（题材/风格/景别/打光等）

编辑 `js/data.js`，都是纯常量对象，改完刷新即可。

### 想改推荐逻辑（分镜怎么拆、参数怎么配）

编辑 `js/templates.js` 的 `SHOT_REC` 映射表和各 `gen*` 函数。

### 想改界面 / 交互

编辑 `js/app.js`（渲染与状态机）+ `css/style.css`（样式）。

### 重新生成单文件版

源码改动后，跑一次构建脚本即可：`python3 build.py`（产物 `dist/short-drama-master-h5.html`）。

## ✅ 测试状态

两个可直接在命令行跑的验证脚本（都不需要装依赖、不需要开浏览器）：

**1. 生成引擎回归 —— 改 `data.js` / `templates.js` 后必跑**

```bash
node _validate.js
```

对男主 / 女主 / 末世 3 个样本跑完整流水线，打印主角性别外观、角色真名、剧本、分镜描述与台词、提示词首行，并断言提示词里**不出现**「反派/女主/配角」占位名。

**2. 端到端 —— 改 `app.js` / `css` 后必跑（测的是真实单文件产物）**

```bash
node _e2e.js
```

用 DOM 桩驱动真实交互链路：新建项目 → 填梗概 → 一键流水线 → 切「剧本 / 分镜 / 提示词」子页 → 编辑剧本字段 → 断言已写入 localStorage → 切集不报错。

> ⚠️ 顺序别反：先跑这两个脚本，再 `python3 build.py`，否则测的是构建前的旧产物。

> ⚠️ 单次跑完 `build.py` 只是**重新产出**单文件，不代表功能没问题——`dist/` 是构建产物，源码改完必须先 `node _validate.js` 再 `python3 build.py`，否则交付的仍是旧行为。
